The release assets are available only after successful gated publication at
[GitHub Releases](https://github.com/wickidcow/Slimefun-Legacy/releases).
Until then, this file describes the **4.1.73 candidate**, not an installed fix
or a published downloadable JAR.

## 🛠️ Shulker Helmet compatibility fix

Fixes `NoSuchMethodError: EntityPotionEffectEvent.getEntity():LivingEntity`
from the restored SHULKER_HELMET levitation listener when running on
Paper/Purpur **1.21.11**. Regular Slimefun armor and Beacon Plus potion-effect
applications could both trigger the listener despite the helmet being disabled
or unworn. The event handler now uses the stable EntityEvent getter descriptor.

The original `SHULKER_HELMET` ID, item data, recipe, shulker-bullet protection,
levitation prevention and other armor behavior remain unchanged. No items,
world data, storage, or configs are migrated. Core fix:
[PR #366](https://github.com/wickidcow/Slimefun-Legacy/pull/366).

## Platform support and release requirements

Retain the Minecraft **1.21.11** minimum; Paper/Purpur 1.21.11,
26.2 and 26.3 validation; primary Paper 26.3 API target; Java 21 bytecode;
and the established Folia/Leaf experimental boundaries. No unrelated
compatibility claims or automatic data migrations are introduced.

Release exactly three artifacts through the existing gated, reproducible
pipeline only: `Slimefun-Legacy4.1.73.jar`, the r130 canonical addon ZIP,
and the unchanged approved optional resource pack. The pipeline must prove
exact-source 45-member validation, API and runtime regressions, and two
byte-identical clean core builds before publication. Do not overwrite
older release tags or replace old published assets.

Stop the server for installation, back up world/plugin data, remove old
duplicate JARs, install the exact matched core plus addons, then start
normally; never use `/reload`. Verify potion-effect logs, Beacon Plus
effects, and the updated Networks/InfinityExpansion2 behaviors in a clone.
