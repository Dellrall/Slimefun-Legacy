# Slimefun Legacy 4.1.76 — Guide Startup Reliability

Slimefun Legacy 4.1.76 coordinates the JustEnoughGuide startup dependency fix with the 45-addon **r142** bundle. It carries forward the core fixes released in 4.1.75 and uses that exact published source as the release-blocking compatibility baseline.

## JustEnoughGuide 2.1.73

JustEnoughGuide packages its existing Pinyin search libraries and dictionaries in the addon JAR. Guide startup therefore no longer needs to acquire these libraries from an external repository. This resolves the startup failure recorded in [the guide dependency follow-up](https://github.com/wickidcow/Slimefun-Legacy/issues/378#issuecomment-6206736869).

The update preserves the existing Pinyin dependency versions, dictionary contents, public Pinyin API names, guide ownership, item and recipe identities, and saved data. Normal Pinyin search remains available with the bundled libraries.

## Coordinated addon bundle

The canonical download remains **SF_Addons_1.21.11-26.3.zip**. Its internal manifest advances from revision **141** to **142** and records the exact core source used by this release.

| Updated addon | Previous version | Version in r142 |
| --- | --- | --- |
| JustEnoughGuide | 2.1.72 | 2.1.73 |

The other **44 addon source pins** remain those selected for r141. This includes Networks 1.0.59, MagicExpansion 1.1.16, InfinityExpansion2 2.0.14, and FinalTECH 3.0.16. Each packaged JAR has a source record and a SHA-256 checksum generated from this release's bundle build.

The retained native probes accept r142 with the exact existing Networks and MagicExpansion source pins. Their previous revision cases, changed-source refusals, checksum checks, and native transaction assertions remain active.

## Core and compatibility baseline

The active metadata advances together to **4.1.76**. The release-blocking previous stable baseline is **4.1.75**, pinned to source `7f702e3565a381aeeefd99555f2c8fe818858e9c`. The historical 4.1.15 floor remains advisory.

This successor carries the atomic backpack save fix already published in 4.1.75. It introduces no new core gameplay, storage-schema, item-identity, or saved-data changes.

Minecraft **1.21.11+** remains the support floor and the distributable bytecode target remains **Java 21**. Paper 26.3 is the primary API/runtime validation target on Java 25. Existing Paper/Purpur compatibility lanes and the experimental Folia scope remain as defined in the support contract.

## Publication and retained releases

The release workflow requires the core JAR and canonical addon bundle to identify the same exact source commit. It verifies two independent clean core builds, the complete addon bundle, and the pinned official resource pack before publication.

The new v4.1.76 release contains these three assets:

- `Slimefun-Legacy4.1.76.jar`
- `SF_Addons_1.21.11-26.3.zip`
- `SlimefunLegacyRP.zip`

The published v4.1.75 and v4.1.74 assets retain their original identities and bytes. The official resource-pack pin is unchanged.
