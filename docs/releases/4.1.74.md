# Slimefun Legacy 4.1.74 — Energy Network Stability Candidate

**Candidate only — not yet published or deployed.** The current installed/released core is **4.1.73**, and the verified published addon ZIP remains **revision 134**, with 45 maintained addons. The canonical release system publishes only from a separately approved workflow_dispatch after a matching exact-source bundle, two reproducible core builds and runtime/migration gates succeed.

## Core fix

- [PR #377](https://github.com/wickidcow/Slimefun-Legacy/pull/377) merged the EnergyNet transport-state refresh fix at source commit `4727e4d23f67eb3afe68a77b58997b6637a2ea79`. Its previous `(world tick + regulator hash) % 20 == 0` test could permanently miss revalidation on some fixed machine-tick phases.
- Transport connector/redstone presentation state now uses a **per-network refresh deadline**: preserve initial staggering, immediately update on topology/power changes, and periodically revalidate even on fixed ticker cadences or after a world-time rewind.
- No energy production, consumption, transfer ordering, generator/capacitor contents, persistent storage key, recipe, machine tick rate, research or item ID is intentionally changed.
