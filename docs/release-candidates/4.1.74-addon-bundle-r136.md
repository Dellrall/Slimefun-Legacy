### Networks

The 1.0.55 candidate prevents Networks Expansion directional line grabbers from routing a deposit back into the very source storage block (matching world and block X/Y/Z). It retains 1.0.54's strict source-side commit verification and compensation on genuine external inventory changes. Two source-routing tests cover a barrel and a cell; a different block in the same X/Z column stays eligible. This is **not** proof that every observed Albion warning was caused by this scenario. The affected source setup was logged around `world`, X `-5278`, Z `-5513`, several negative Y levels.

### MagicExpansion

The 1.1.12 candidate adds OP-only `/magicexpansion blackmarket status` to inspect market-cycle consistency **without changing files or transactions**. It reports byte-identical, rewritten-same-cycle, different-cycle, missing, unreadable and not-loaded states. It does not unlock trading, reset purchase receipts, regenerate trades or resolve a production file mismatch by itself.
